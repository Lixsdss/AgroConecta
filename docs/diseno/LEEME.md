# docs/diseno

Coloca aquí los entregables de diseño (APF2) en formato Markdown, PDF o imagen:

- `modelo-bd.md` — diseño lógico/físico de la base de datos (tablas, columnas, PK/FK). **Claude Code lo usa como fuente de verdad para las entidades y migraciones.**
- `bpmn/` — diagramas AS-IS y TO-BE exportados (PNG/PDF).
- `prototipos/` — capturas o HTML de las pantallas.
- `casos-de-uso.md` — casos de uso y flujos principales.
